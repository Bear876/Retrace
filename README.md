# Retrace

Retrace is a web application that audits the methods section of a scientific paper or lab report to surface missing or ambiguous operational details needed to repeat the work.

## What It Checks

Retrace evaluates methods text against a nine-category reproducibility checklist:

1. **Materials and reagents**: Catalog numbers, vendor names, strains, cell lines, or dataset identifiers.
2. **Quantities and concentrations**: Exact masses, volumes, molarities, dilutions, dosages, or sample sizes.
3. **Equipment and settings**: Instrument models, rotor speeds, wavelengths, objectives, or compute hardware.
4. **Conditions**: Temperatures, durations, pH, atmosphere, lighting, or training schedules.
5. **Samples and replicates**: Biological vs. technical replicates, randomization, and exclusion criteria.
6. **Controls**: Positive, negative, vehicle, sham, or baseline comparison groups.
7. **Software and versions**: Software names, package versions, and non-default parameters.
8. **Statistical methods**: Named tests, assumption checks, multiple-testing corrections, and variance metrics.
9. **Data and code availability**: Repository links, accession numbers, or explicit access conditions.

Categories that do not apply to the study type (for example, wet-lab reagents in a pure computational benchmark) are skipped and listed separately rather than penalized.

## Key Features

- **Try a sample without an API call**: Includes three built-in presets (*Wet-Lab qPCR Assay*, *ML Classification Study*, and *Field Ecology Transect*) with precomputed findings for instant exploration.
- **Linked highlight navigation**: Verified verbatim quotes are highlighted directly inside the methods text. Clicking a highlight jumps to its finding card, and clicking a finding card or its **Locate** button scrolls to and highlights the matching passage.
- **Status filtering and copyable fixes**: Filter findings by *All*, *Missing*, *Unclear*, or *Reported*, and copy suggested text additions directly to your clipboard.
- **Accessibility**: Includes `focus-visible` keyboard outlines, an `aria-live="polite"` results panel, non-hue-only status indicators, and a responsive layout that stacks cleanly on mobile.

## Responsible AI Safeguards

- **Verbatim quote verification**: Every quote returned by the model is checked character-for-character against your submitted text. Quotes that do not match verbatim are marked as unverified and are never highlighted.
- **Code-computed finding count**: Summary counts are calculated deterministically in code (`reported = 1`, `unclear = 0.5`, `missing = 0`), never generated by the model, and explicitly labeled as an applicable finding count rather than a quality grade.
- **Narrow methodological claims**: Retrace flags missing operational detail only. It never claims whether results are true or whether the underlying science is valid.
- **Stateless inspection**: Submitted methods drafts are audited in-session and are not persisted to a database.

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons
- **Backend**: Express (`server.ts`) with `@google/genai` (`gemini-4-hydrogen`) using schema-constrained JSON output (`responseMimeType: "application/json"` and `responseSchema`)
